# 课标统领的教材脉络图

这是可直接打开的静态网页快照，入口为 `index.html`，不需要安装依赖或请求外部资源。页面整理小学语文教材单元要素与课标依据，并区分跨单元能力脉络、同单元关联和人文主题检索。教材先后顺序不代表能力等级；学业质量条文是课程标准参照，不等同于单元达成量规。

## 文件

- `index.html`：2026-10-10 核定版网页。
- `续作交接_2026-10-06/curriculum_data.json`：页面维护数据。
- `logic.js`、`styles.css`：交互与样式源码。
- `make_deliverable.py`：构建脚本。
- `课标统领的教材脉络图_单元要素版.html`：构建器使用的基准页。
- `release-manifest.json`：交付文件 SHA-256 与核验边界。

## 本地重建

需要 Python 3（仅使用标准库）。在仓库根目录运行：

```powershell
python make_deliverable.py
Copy-Item -LiteralPath '课标统领的教材脉络图_导出版.html' -Destination 'index.html' -Force
```
