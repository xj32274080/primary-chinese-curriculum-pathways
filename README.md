# 课标统领的教材脉络图

这是可直接打开的静态网页快照，入口为 `index.html`，不需要安装依赖或请求外部资源。页面整理小学语文教材单元要素与课标依据，并区分跨单元能力脉络、同单元关联和人文主题检索。节点较多的宽口径能力线先显示此前、此后各至多两个代表节点，其余节点可按需展开；同线不表示每项都与当前要素高度相关。简洁脉络图中只列教材顺序上的近邻代表项。六上第七单元“展开想象，试着写科幻故事”采用聚焦视图，只突出明确同时涉及想象与故事创编的四个前置任务；一般叙事要素仍可在“表达组织”索引中查看，版次待核的同题材条目不作为确定的后续进阶。也可使用详细 PNG、PDF 或 Markdown 查看完整脉络。教材先后顺序不代表能力等级；学业质量条文是课程标准参照，不等同于单元达成量规。

## 文件

- `index.html`：静态网页入口。14项及以上的宽口径路径默认显示此前、此后各至多两个代表节点，剩余节点可分别展开；六上第七单元聚焦展示“想象与故事创编”任务线索。简洁 PNG 对宽索引只列此前、此后的近邻代表项；详细导出保留完整脉络。
- `续作交接_2026-10-06/curriculum_data.json`：页面维护数据。
- `logic.js`、`styles.css`：交互与样式源码。
- `make_deliverable.py`：构建脚本。
- `课标统领的教材脉络图_单元要素版.html`：构建器使用的基准页。
- `release-manifest.json`：交付文件 SHA-256 与核验边界。

## 本地重建

需要 Python 3（仅使用标准库）。在仓库根目录运行：

```powershell
python make_deliverable.py
Copy-Item -LiteralPath '课标统领的教材脉络图_导出版.html' -Destination 'index.html' -Force
```
